# Repository Instructions

This repository is minimal and currently centered around the file [README.txt](README.txt).

## Working conventions
- Keep changes small and straightforward.
- Preserve the existing repository layout unless a clear need for new files is introduced.
- Treat [README.txt](README.txt) as the primary place for human-facing project notes.
- Do not assume build tools, test suites, package managers, or application frameworks are present.

## When making changes
- Prefer simple edits over introducing new structure.
- If new documentation is needed, update [README.txt](README.txt) rather than creating extra docs unless the change clearly warrants it.
- If a task would require a larger project setup, explain that explicitly before adding new files or dependencies.
